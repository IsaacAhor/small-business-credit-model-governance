# Data Policy

This repository is public-facing and governance-oriented. It should not contain
private production underwriting data, customer-level credit records, or sensitive
business records.

## Allowed Data

- synthetic data created for demonstration
- simulated data with documented assumptions
- public or licensed datasets with documented permitted use
- aggregate examples that cannot identify a person, applicant, or business

## Required Documentation

Any data-like artifact should document:

- source or generation method
- synthetic, proxy, public, or production status
- permitted use
- sensitivity classification
- reviewer
- linked notebook, report, or framework section

## Prohibited Without Explicit Approval

- customer-level credit records
- applicant-level financial statements
- bank transaction records
- tax records
- personally identifiable information
- business-identifiable confidential records

## Demonstration Standard

Synthetic and proxy data should be labeled clearly. Demonstration artifacts
should not imply production deployment, production validation, or institution
adoption unless that evidence is separately documented.
