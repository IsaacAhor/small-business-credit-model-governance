# Synthetic Recourse Assessment Fixtures

These directories exercise the separate reviewer-facing recourse sidecar. Use
them with `data/synthetic/adverse-action-reason-benchmark` as the core dataset.

All values, subjects, action candidates, and model rules are fictional. The
fixtures do not represent real applicants, lenders, production models,
institutional policies, legal conclusions, or applicant guidance.

See `docs/recourse-assessment-run-kit/README.md` for commands, expected statuses,
method boundaries, and the invalid-fixture matrix.
