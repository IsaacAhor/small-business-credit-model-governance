# v0.4.0: Phase 4 Fair-Lending Screening Demo

## Release Summary

`v0.4.0` is the first stable public milestone release for the credit model
governance evidence engine. It packages the repository after completion of
Phases 0 through 4 and after reviewer-facing project packaging was added.

## What This Release Demonstrates

- A documented system design for a small business credit model governance
  evidence engine.
- JSON data contracts and typed validation for synthetic governance records.
- Cross-file evidence-integrity validation across model, version, run, threshold,
  decision, breach, reason, and manifest records.
- A one-command monthly monitoring workflow that generates synthetic
  evidence-pack outputs.
- Adverse-action reason QA checks and traceable reason-review outputs.
- Fair-lending screening triggers, escalation findings, issue records, reviewer
  notes, and signoff placeholders.
- Reviewer-facing orientation materials, references, and an evidence map.

## Included Reviewer-Facing Artifacts

- `README.md`

## Reproduction Commands

```bash
python scripts/validate_repository.py
python scripts/validate_phase1.py
python scripts/run_monthly_monitoring.py data/synthetic/monthly-demo --evidence-root evidence
python -m unittest discover -s tests -p "test_*.py"
```

## Limitations

- Synthetic data only.
- No production lender deployment is claimed.
- Fair-lending outputs are screening triggers, not legal conclusions.
- Adverse-action reason QA outputs are governance checks, not legal advice.
- Reviewer signoff artifacts are illustrative placeholders.
- This release does not claim external adoption, independent recognition, or
  regulatory approval.
