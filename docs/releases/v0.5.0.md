# Release v0.5.0

Date: 2026-07-01

Synthetic demonstration milestone. Not production deployment, institutional
adoption, or regulatory acceptance.

## Summary

This release turns two endeavor phrases into shown, runnable work and puts them
on a realistic dataset:

- **Adverse-action reason generation (Phase 3B).** A new generation step derives
  adverse-action reasons from ranked, per-decision driver contributions and the
  governed reason-code mapping. Generation is separate from the existing reason
  QA, which reviews the generated output. Adds `src/credit_gov/generation.py` and
  `scripts/generate_adverse_action_reasons.py` (with a `--check` drift mode).
- **Less-discriminatory-alternative assessment (Phase 4B).** A new module compares
  a baseline model to a candidate alternative on the same synthetic population,
  measuring predictive separation and group approval-rate disparity, and flags a
  qualifying alternative as a documented review trigger. Adds
  `src/credit_gov/lda.py`, `scripts/run_lda_assessment.py`, and an optional hook
  in the monitoring workflow that emits `lda_assessment_results.json` and a
  report section when LDA inputs are present.
- **Portfolio-scale synthetic dataset.** `data/synthetic/monthly-portfolio` (320
  decisions) generated deterministically by `scripts/build_portfolio_dataset.py`.
  At this volume the monthly run produces an override-rate breach, a regional
  fair-lending finding, a realistic reason-QA exception, and a qualifying LDA
  finding.

## Tests

Full suite passes (29 tests), including new `tests/test_phase3b_reason_generation.py`
and `tests/test_phase4b_lda_assessment.py`. Existing `monthly-demo` behavior is
unchanged (datasets without LDA inputs run exactly as before).

## Limitations

- All data is synthetic; no protected-class labels are used.
- LDA predictive separation uses synthetic outcome labels; real declined
  applicants lack outcomes (reject inference). A positive LDA finding is a
  governance review trigger, not a legal conclusion or a mandate to adopt an
  alternative.
- Reason generation is a synthetic demonstration, not a production adverse-action
  notice process.
