# v0.6.1

Documentation release. No functional changes.

## Summary

- Standardizes project-objective wording and reviewer-facing role
  descriptions across `README.md`, `START_HERE.md`, `USE_CASES.md`, and
  `docs/`.
- Adds a curated portfolio-scale example evidence pack under
  `examples/evidence-packs/monthly-portfolio/`, generated deterministically
  from `data/synthetic/monthly-portfolio/`, so reviewers can inspect
  statistical significance results, BISG proxy screening, and the LDA
  assessment without running code.
- Updates model-risk-guidance references to the April 2026 revised
  interagency guidance (SR 26-2 / OCC Bulletin 2026-13), which supersedes
  SR 11-7 / OCC Bulletin 2011-12.

## Scope Notes

Synthetic demonstration milestone. Not production deployment, institutional
adoption, or regulatory acceptance.
