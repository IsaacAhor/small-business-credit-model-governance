# Release v0.10.0 - Fixed-Horizon SBA Public-Data Monitoring

Status: public-data methodology and reproducibility milestone.

Release date: 2026-08-22

Git tag: [v0.10.0](https://github.com/IsaacAhor/small-business-credit-model-governance/tree/v0.10.0)

## What This Release Adds

- Accepts the current separate SBA 7(a)/504 FOIA CSV layouts and multiple input
  files while recording each source URL, size, SHA-256 hash, row count, and
  observed as-of date.
- Normalizes current loan-status values, including `P I F`, and separately
  counts canceled, invalid, pre-FY2010, unseasoned, unsupported, and
  charge-off-without-event-date rows.
- Defines default at a configurable fixed horizon from
  `FirstDisbursementDate`, `ChargeOffDate`, and `AsOfDate`, including seasoned
  `EXEMPT` loans as nondefaults at the horizon.
- Fits the demonstration logistic regression only on a pre-monitoring
  development population and reports development and out-of-time monitoring
  AUC, Brier score, mean probability, default rate, and calibration gap.
- Reports numeric and categorical population-stability indexes against the
  development population and labels the interpretive bands as demonstration
  review bands.
- Adds `monitoring-applicability.json` so approved-loan data can record
  decision-rate, manual-review, override, adverse-action-reason, and
  fair-lending modules as not applicable instead of generating placeholders.
- Preserves backward compatibility: datasets without the optional
  applicability file retain their prior behavior. Applicable fair-lending
  configurations still require nonempty comparison groups and screens; empty
  arrays require explicit nonapplicability and a reason.
- Consolidates each command-line script as a thin wrapper over the packaged
  implementation and updates the current-schema synthetic fixture.
- Writes methodology, environment, exact invocation, implementation hashes,
  full-cohort summaries, evidence-pack samples, and generated-output hashes.

The dedicated adapter tests cover current status spacing, fixed-horizon event
timing, seasoned and unseasoned active loans, cancellations, missing event
dates, unsupported statuses, applicability validation, not-applicable report
rendering, and the source/package schema contract.

## Interpretation Boundary

SBA FOIA is approved-loan data. It does not contain the full application
decision population, model-driver provenance, adverse-action notices,
manual-review or override events, or applicant protected-class fields.

Accordingly, this release does not establish approval or decline rates,
fair-lending outcomes, adverse-action accuracy, underwriting-model validity,
institutional adoption, independent validation, production deployment, legal
compliance, regulatory approval, field recognition, or examiner acceptance.
The demonstration PSI bands are not universal policy thresholds, and observed
drift does not establish a cause.
