# v0.6.3

Documentation release. No functional changes.

## Summary

- Expands the statistical methodology note with additional stated
  limitations: post-hoc extreme-pair selection in disparity significance
  testing, the decision-level separation proxy used by the LDA assessment,
  and instability of the min/max disparity ratio with small groups.
- Reframes the remaining Phase 8 roadmap deliverables as a single build: a
  reproducible public-data run that trains an interpretable reference model,
  supplying real driver contributions, full Census-derived BISG tables,
  regression controls, and the LDA candidate search space.

## Scope Notes

Synthetic demonstration milestone. Not production deployment, institutional
adoption, or regulatory acceptance.
