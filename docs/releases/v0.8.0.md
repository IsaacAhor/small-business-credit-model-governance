# v0.8.0

Synthetic adverse-action reason accuracy and transparency run kit.

## What This Release Adds

- `docs/adverse-action-reason-run-kit/METHOD.md`: method note for adverse-
  action reason generation, mapping, QA, and evidence-pack review under
  Regulation B 12 CFR 1002.9.
- `docs/adverse-action-reason-run-kit/PUBLIC_DATA_LIMITS.md`: public-data boundary note
  explaining why SBA, PPP, CRA, and 1071 data cannot currently prove adverse-
  action reason accuracy, and how HMDA may be used only as an off-domain
  mechanics proxy.
- `docs/adverse-action-reason-run-kit/PRIVATE_DATA_SPEC.md`: deidentified private-data
  field specification for a future lender/CDFI/fintech validation run.
- `data/synthetic/adverse-action-reason-benchmark/`: synthetic small-business
  benchmark inputs with controlled adverse-action reason QA failures.
- `scripts/run_adverse_action_reason_benchmark.py`: one-command benchmark
  workflow that runs monitoring, records benchmark-specific checks, and writes
  a curated evidence pack.
- `examples/evidence-packs/adverse-action-reason-benchmark/`: reviewer-facing
  synthetic evidence pack for the benchmark.

## What This Release Demonstrates

This release demonstrates a reproducible public method for testing adverse-
action reason generation, driver-to-reason mapping, reason-code QA, mapping-
version integrity, excessive-reason detection, non-declined reason-output
detection, and reviewer-ready evidence packaging.

## Limitations

- The benchmark is synthetic and does not represent production lending
  decisions.
- The benchmark is not legal advice and does not certify Regulation B
  compliance.
- The release does not show lender adoption, production deployment, external
  validation, regulatory approval, or field recognition.
- Public small-business datasets currently do not provide declined applications
  with reasons or notices plus actual decision drivers, so real-world reason
  accuracy remains a private-data validation gap.
- HMDA remains off-domain and should be used only for reason-code mechanics if
  a later proxy run is added.

## Scope Notes

This is an adverse-action reason accuracy and transparency milestone. It is not
a fair-lending screening milestone, an LDA milestone, or a public-data proof of
small-business notice accuracy.
