# Release v0.9.0 - Installable Package Readiness

Status: package-readiness milestone; publish only after final repository scan,
CI build success, and package-name control are confirmed.

## What This Release Adds

- Adds `pyproject.toml` with modern Python package metadata for the `credit-gov`
  distribution and `credit_gov` import package.
- Adds installed console entry points for validation, monitoring, reason
  generation, BISG screening, LDA assessment, model-change review, and optional SBA public-data runs.
- Packages JSON schema resources and demonstration BISG reference tables so the
  installed wheel can validate datasets and run BISG-backed synthetic demos
  without relying on a source checkout.
- Adds repository guardrails that check packaged resources stay synchronized
  with reviewer-facing root copies under `schemas/` and `data/reference/bisg/`.
- Updates CI to build distribution artifacts, install the built wheel, and run
  installed-command smoke tests before source-tree script tests.
- Adds a PyPI release guide with TestPyPI, PyPI, preservation, and claim-safety
  steps.

## Verification Commands

```bash
python -m pip install --upgrade pip build twine
python -m build
python -m twine check dist/*
python -m pip install --force-reinstall dist/*.whl
credit-gov-validate data/synthetic/monthly-demo
credit-gov monitor data/synthetic/monthly-demo --evidence-root evidence
credit-gov change-review data/synthetic/monthly-portfolio
python scripts/validate_repository.py
python -m unittest discover -s tests -p "test_*.py"
```

## Limitations

This release makes the project installable and publishable as a Python package.
It does not establish production deployment, lender adoption, legal compliance,
regulatory approval, external validation, field recognition, or meaningful
package-download demand. Those signals require independent evidence outside the
package metadata and build logs.
