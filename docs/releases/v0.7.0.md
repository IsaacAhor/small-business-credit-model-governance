# v0.7.0

model-risk oversight public-data run kit.

## What This Release Adds

- `scripts/sba_to_monitoring.py`: an adapter that reads SBA 7(a)/504 FOIA
  loan-level data, cleans FY2010+ matured loans, trains a transparent
  demonstration default-risk model, builds monthly monitoring cohorts, runs the
  Phase 2 workflow per cohort, and writes a cross-cohort drift summary.
- `scripts/make_sba_fixture.py`: a synthetic schema fixture generator for
  validating the SBA adapter and monitoring workflow without committing raw SBA
  inputs or scratch outputs.
- `docs/model-risk-oversight-run-kit/README.md`: a reproducibility guide for obtaining the public
  SBA file, running the adapter, interpreting outputs, and recording provenance.
- `docs/model-risk-oversight-run-kit/LIMITATIONS.md`: a candid scope and limitations note for the
  SBA run.
- `.gitignore` exclusions for raw public-data inputs and scratch outputs:
  `data/*.csv`, `data/*FIXTURE*`, `sba_run/`, and `sba_run_fixture/`.

## What This Release Demonstrates

A reproducible public-data run kit for exercising model-risk monitoring and
drift reporting on real federal small-business lending records. The run kit
shows how the governance evidence workflow can be adapted from synthetic
fixtures to a clearly scoped public dataset while preserving provenance,
limitations, and reviewer-readable outputs.

## Limitations

- The SBA model is a governed-model stand-in, not an underwriting model.
- SBA 7(a)/504 FOIA data is approved-only and does not include declines or
  applicant demographics, so fairness analysis, protected-class analysis,
  less-discriminatory-alternative assessment, and adverse-action interpretation
  are out of scope for this dataset.
- The run kit supports integration and reproducibility, not lender adoption,
  production deployment, institutional reliance, legal conclusions, regulatory
  approval, or evidence of novel statistical methods.
- Raw public-data inputs and scratch outputs are intentionally git-ignored; any
  curated example outputs should be committed deliberately under the repository's
  existing example-pack pattern.

## Scope Notes

Public-data monitoring milestone. Not production deployment, institutional
adoption, external recognition, regulatory acceptance, or evidence of small
business application-level fairness outcomes.
