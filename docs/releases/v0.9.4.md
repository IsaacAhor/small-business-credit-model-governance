# Release v0.9.4 - Curated Evidence-Pack Verification Completeness

Status: public technical-control and reviewability patch.

Release date: 2026-08-20

Git tag: [v0.9.4](https://github.com/IsaacAhor/small-business-credit-model-governance/tree/v0.9.4)

## What This Release Adds

- Recognizes `README.md` as explanatory documentation when verifying a curated
  example evidence pack. The README remains outside the declared, hashed
  evidence-artifact set.
- Continues to reject every other undeclared file in an evidence pack.
- Adds regression coverage that verifies all three checked-in example packs:
  the minimal monthly demo, the portfolio-scale monthly pack, and the
  adverse-action reason benchmark.

## Verification Commands

```bash
python scripts/validate_repository.py
python -m unittest discover -s tests -p "test_*.py"
credit-gov verify-evidence examples/evidence-packs/monthly-demo
credit-gov verify-evidence examples/evidence-packs/monthly-portfolio
credit-gov verify-evidence examples/evidence-packs/adverse-action-reason-benchmark
```

## What This Release Does Not Demonstrate

This patch changes evidence-pack verification behavior only. It does not alter
the synthetic underwriting, fair-lending, adverse-action, or model-change
results in the checked-in packs.

It does not establish adoption, external validation, production deployment,
legal compliance, regulatory acceptance, field recognition, or examiner
acceptance.
