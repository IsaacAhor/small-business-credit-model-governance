# Release v0.9.3 - Sample-Aware Screening and Verified Evidence Packs

Status: public technical-control and reviewability milestone.

Release date: 2026-08-20

Git tag: [v0.9.3](https://github.com/IsaacAhor/small-business-credit-model-governance/tree/v0.9.3)

## What This Release Adds

- Adds `minimum_group_size` and `alpha` to each fair-lending screening
  configuration.
- Requires rate-screen threshold observations to meet the configured minimum
  group size and statistical-significance gate before they create an escalation
  finding or linked issue.
- Retains threshold observations that do not meet either gate as explicit,
  reviewer-visible inconclusive results with their non-escalation reason.
- Treats reason-code concentration as a descriptive governance screen: it must
  meet the configured minimum group size but does not claim an inferential test.
- Exercises both published evidence-pack verification commands in CI after the
  wheel is built and installed.
- Regenerates the curated monthly example evidence packs to match the current
  gate behavior and source-input fingerprints.

## Verification Commands

```bash
python scripts/validate_repository.py
python scripts/validate_phase1.py
python -m unittest discover -s tests -p "test_*.py"
python -m build
credit-gov monitor data/synthetic/monthly-demo --evidence-root .tmp-evidence
credit-gov verify-evidence .tmp-evidence/<generated-evidence-pack-directory>
credit-gov-verify-evidence .tmp-evidence/<generated-evidence-pack-directory>
```

## What This Release Does Not Demonstrate

This release remains a synthetic public demonstration. The screening gates do
not establish legal compliance, make a causal inference, substitute for
regression controls or institution-specific review, or validate a production
underwriting system.

It does not establish adoption, external validation, production deployment,
regulatory acceptance, field recognition, or examiner acceptance.
