# Release v0.6.0

Date: 2026-07-02

Synthetic demonstration milestone. Not production deployment, institutional
adoption, a legal conclusion, or regulatory acceptance.

## Summary

This release strengthens the analytical-rigor layer of the governance evidence
engine:

- **Statistical significance testing for fair-lending screens.** Every reported
  disparity screen now carries a test name, p-value, effect size, sample
  adequacy flag, and caveats. Large enough samples use a pooled two-proportion
  z-test; small samples fall back to Fisher's exact test.
- **BISG proxy monitoring.** The monthly monitoring workflow can optionally run
  Bayesian Improved Surname Geocoding using documented demonstration reference
  tables and applicant proxy inputs. Outputs include proxy-weighted disparity
  metrics, a dedicated `bisg_proxy_results.json` artifact, and a monitoring
  report section.
- **Portfolio-scale synthetic evidence.** The synthetic monthly portfolio now
  includes demonstration demographic-proxy inputs and configuration so the
  significance and BISG workflows can be reviewed end to end.
- **Documentation and citation readiness.** Adds `docs/fair-lending-statistics.md`,
  Apache-2.0 licensing, `CITATION.cff`, and release documentation for the
  analytical-rigor milestone.

## Limitations

- BISG outputs are probabilistic protected-class proxies, not observed
  demographic labels.
- The included BISG reference data is demonstration data and is not sufficient
  for production fair-lending analysis.
- Statistical significance results are screening signals only. They are not
  causal estimates, regression-controlled findings, legal conclusions, or proof
  of discrimination.
- The repository remains a synthetic public demonstration and should not be
  described as institutional adoption or regulatory compliance evidence without
  independent external validation.
