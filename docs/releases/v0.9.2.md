# Release v0.9.2 - Reviewability and Evidence-Pack Stability

Status: public documentation and synthetic-control milestone.

Release date: 2026-08-12

Git tag: [v0.9.2](https://github.com/IsaacAhor/small-business-credit-model-governance/tree/v0.9.2)

## What This Release Adds

- Adds source class, applicability, and checked-on fields to the credit-union
  vendor-risk source map. The patch distinguishes binding requirements when
  applicable, NCUA guidance, and voluntary or analogous references.
- Adds business-credit notice-path, retention, consumer-report, electronic-
  record, Section 1071, contractual-event, and institution-led escalation
  prompts without deciding applicability for a specific institution.
- Reframes monitoring cadence as a risk-based configuration with documented
  rationale and heightened-monitoring triggers.
- Adds synthetic source-to-rendered-notice fidelity checks to the
  adverse-action benchmark, including source driver, reason text, decision
  component, mapping, policy, selection-method, and rendered-notice controls.
- Normalizes newline bytes before evidence-pack input fingerprinting so a
  Windows CRLF checkout and Linux LF checkout produce the same input hashes.
- Regenerates the affected synthetic evidence-pack fingerprints and adds a
  regression test for cross-platform fingerprint stability.

## What This Release Does Not Demonstrate

This release remains a synthetic public demonstration and reviewer-facing
documentation update. It does not determine legal applicability, establish
Regulation B, FCRA, E-SIGN, Section 1071, Part 723, or cybersecurity compliance,
or provide a vendor-specific reportability determination.

It does not establish NCUA approval, credit-union adoption, external validation,
production deployment, legal compliance, regulatory acceptance, field
recognition, or examiner acceptance. The vendor-risk profile is still
pre-implementation until the separate executable vendor-oversight build is
released.
