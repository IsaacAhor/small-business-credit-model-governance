# Release v0.9.1 - Credit Union AI Vendor-Risk Run Kit

Status: documentation and reviewer-profile milestone.

Release date: 2026-08-05

Git tag: [v0.9.1](https://github.com/IsaacAhor/small-business-credit-model-governance/tree/v0.9.1)

## What This Release Adds

- Adds `docs/credit-union-ai-vendor-risk-run-kit/`, a credit-union-facing
  profile for AI-enabled small-business or member-business underwriting vendor
  review.
- Adds source mapping from public NCUA AI, financial-technology,
  third-party-risk, compliance-management, Regulation B, and CUSO resources to
  practical review controls.
- Adds an AI vendor due-diligence questionnaire covering use case, business fit,
  vendor background, model function, transparency, data security,
  adverse-action reason support, fair-lending risk screening, operational
  controls, contract review, and oversight records.
- Adds an ongoing monitoring protocol covering owners, cadence, metrics,
  evidence packs, breach handling, model-change review, board or management
  reporting, and reviewer signoff.
- Adds an adverse-action reason review path for business-credit workflows,
  including reason traceability, specificity, mapping integrity, change
  stability, override clarity, and retention prompts.
- Adds limitations that explicitly avoid NCUA approval, credit-union adoption,
  examiner acceptance, legal compliance certification, production deployment, or
  external validation claims.
- Adds `docs/ai-rmf-alignment.md`, a practical NIST AI RMF orientation document
  that is useful because the NCUA AI resource page points credit unions to NIST
  AI resources.
- Updates reviewer entry points, evidence mapping, references, roadmap notes,
  repository guardrails, package version metadata, and citation metadata for the
  `v0.9.1` milestone.

## What This Release Demonstrates

This release demonstrates how the existing governance evidence engine can be
packaged for a credit-union AI underwriting vendor-risk review. It connects
third-party due diligence, AI risk management, adverse-action reason review,
model-change review, ongoing monitoring, issue tracking, and reviewer signoff in
one public run-kit profile.

## Limitations

This release is a documentation and reviewer-profile milestone. It does not add
new executable vendor model metadata fields, heightened monitoring code, or a
production vendor oversight report generator. Those remain future implementation
work.

The release does not establish NCUA approval, credit-union adoption, regulatory
acceptance, production deployment, legal compliance, field recognition, external
validation, or examiner acceptance. The credit-union run kit is self-authored
until a qualified external reviewer evaluates the exact artifact and provides
usable feedback.
