# External review packets

Review selected methods and records for model-risk governance, adverse-action
reason traceability, and ongoing oversight of small-business credit models.
The project is a synthetic demonstration. We welcome critical, mixed, or
inconclusive assessments of the work actually examined.

**Starting a new review?** Open the [latest published release](https://github.com/IsaacAhor/small-business-credit-model-governance/releases/latest)
and choose a packet under **Review this release**. That selects the released
version even while the default branch contains work for a future release.
If you already started or received an assignment, use your saved packet and
source instead; a newer release does not replace them.

## Choose your packet

Choose by the work you want to do, using the descriptions below. Each packet
contains its tasks, source identity, essential instructions or prepared
materials, known limitations, and what to return. The links below show the
packets in this repository revision; use the release's links for a new review.

### Technical Implementation Reviewers

[Open the technical review packet](technical-review.md). Reproduce outputs,
inspect implementation, and design independent challenges. Requires Python
and the fixed source. Return execution evidence, challenge results, findings,
and your conclusion.

### Credit Governance and Adverse-Action Reviewers

[Open the credit governance and adverse-action packet](practitioner-assessment.md).
Trace prepared records, assess a governance gap, and specify the next action.
No installation required. Return a short task response and assessment of
practical fit.

### Methodology and Evaluation Reviewers

[Open the methodology and evaluation packet](methodology-assessment.md).
Assess claims, assumptions, reference answers, and evaluation design. No
execution required for the methods-only assignment. Return a short critique
and proposed evaluation improvements.

Use [the group definitions](reviewer-groups.md) to assess fit by experience.
One person may cover multiple functions; record each scope separately. That
does not create multiple independent reviews or organizational endorsement.
For a voluntary review, choose and record your scope and effort cap, then follow
the packet. No prior maintainer agreement is needed. Partial work is a valid
recorded outcome. Invited or commissioned reviews retain their agreed terms.

## Write and submit your report

Each packet has a **Write your review** link to the same
[review form](https://github.com/IsaacAhor/small-business-credit-model-governance/issues/new?template=external-review.yml).
Use the packet's link to prefill its software identity, confirm it, and paste
your saved packet permalink. Select your group and answer the shared fields
using your packet's tasks. Attach or link supporting evidence where needed.
The submitted issue is your report; save its URL. No separate report or pull
request is required.

Submission requires a GitHub account and is public. For private or offline
work, copy/download the [same report headings](review-record-template.md) and
use an agreed private channel. No private inbox is provided by this repository.
Only share material you have permission to share. Partial, negative and
inconclusive reviews are welcome. Completion does not depend on a maintainer
reply; responses and retests are recorded separately from the original report.

The [shared protocol](protocol.md) contains the full agreement, findings,
response, retest, and sharing rules summarized in the packets. The
[fixed target sheet](targets/v0.12.0.md) preserves source references and known
issues. These are supporting references, not a second starting sequence.

These documents do not establish a completed review, correct real-world
notices, model-explanation faithfulness, adoption, or legal compliance.
