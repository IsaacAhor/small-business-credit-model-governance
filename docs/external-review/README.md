# External review packets

Review selected methods and records for model-risk governance, adverse-action
reason traceability, and ongoing oversight of small-business credit models.
The project is a synthetic demonstration. We welcome critical, mixed, or
inconclusive assessments of the work actually examined.

**[Start at the latest release](https://github.com/IsaacAhor/small-business-credit-model-governance/releases/latest)
→ choose one packet → complete its tasks → submit one report.**

The release's **Review this release** section offers the three choices below.
Each packet contains the assignment, source, essential instructions or prepared
materials, limitations, and a **Write your review** link. Start with one packet;
you do not need to work through this folder or the wider repository first.

**Continuing or invited?** Use your saved or supplied packet and its source.
A newer release does not replace an existing assignment or its agreed terms.

## Choose by the work you want to do

| Reviewer group | Work in its packet | Requirements |
| --- | --- | --- |
| **Technical Implementation Reviewers** | Reproduce outputs, inspect implementation and design independent challenges | Python and the fixed source |
| **Credit Governance and Adverse-Action Reviewers** | Trace prepared records, assess a governance gap, specify a next action and assess practical fit | No installation |
| **Methodology and Evaluation Reviewers** | Assess claims, assumptions, reference answers and evaluation design | No execution for the methods-only assignment |

Choose the corresponding link on the release page. Relevant experience,
described in the [group definitions](reviewer-groups.md), determines fit.
A voluntary reviewer chooses a scope and effort cap without prior maintainer
agreement. Partial work is welcome. One person may cover several functions;
record each scope separately without treating it as several independent reviews
or organizational endorsement.

## Write and submit your report

Use **Write your review** in your packet to open the shared
[report form](https://github.com/IsaacAhor/small-business-credit-model-governance/issues/new?template=external-review.yml)
with its software identity prefilled. Keep the packet open for reference, paste
its saved permalink, and answer the form using its tasks. Attach or link
supporting evidence. Submit once and save the issue URL: **that issue is your
report**. No separate document or pull request is required.

Submission requires a GitHub account and is public. For private or offline
work, copy/download the [same report headings](review-record-template.md) and
use an agreed private channel. No private inbox is provided by this repository.
Only share material you have permission to share. Partial, negative and
inconclusive reviews are welcome. Completion does not depend on a maintainer
reply; responses and retests are recorded separately from the original report.
