# Notebooks

This directory is reserved for implementation-oriented notebooks that demonstrate parts of the repository framework.

Initial notebook candidates:

- fairness monitoring with synthetic underwriting data
- explanation quality review workflow
- population and feature drift screening
- less discriminatory alternative comparison template

## Data Discipline

Use synthetic, simulated, or clearly described proxy data unless a dataset is appropriate to disclose and use. Do not imply that demonstration data is actual production underwriting data when it is not.

## Implementation Goal

The notebooks should support the broader framework by showing how monitoring concepts can be operationalized in a transparent and reviewable way.
